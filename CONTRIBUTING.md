# Contributing

Use pnpm, React and strict TypeScript. Read [project conventions](AGENTS.md), [content guidance](docs/content-guide.md) and [AI distribution maintenance](docs/distribution-maintenance.md). Keep prompt IDs stable and preserve Chinese/English UI behavior. Do not commit generated ZIPs, credentials or agent scratch files. Run the documented release checks before proposing a release. Describe static checks, authored simulations, real API runs and browser tests separately.
