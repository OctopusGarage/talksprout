# Security

Do not post credentials, private transcripts or personal scenario background in public issues. Report vulnerabilities privately through GitHub's private vulnerability reporting when available; otherwise contact the repository owner privately before disclosing details. Do not place secrets in a public issue to request a contact channel.

The app stores preferences locally and does not receive AI conversations. AI packages retrieve public learning content. The unauthenticated MCP exposes bundled public documents only, with exact-key access and bounded requests; it must not be extended with private storage without a separate authentication design. External assistants handle material you send under their own policies. Installation does not imply permission to read local app data or execute commands.
