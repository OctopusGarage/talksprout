TalkSprout 0.1.0 includes a self-contained full Skill alongside the existing lightweight Skill and ChatGPT/Claude plugin packages.

The full edition embeds the complete learning library in SKILL.md and is also available as a standalone Markdown attachment. No remote content reader or MCP is needed to use its instructions. Replace the file to update its content. The lightweight edition retains stable remote entry URLs and receives content updates without reinstalling. Choose one Skill edition.

Verify SHA256SUMS before importing. Host upload and context limits apply. Installing a Skill does not grant audio, browsing or private app access. Gemini account compatibility is not certified by the Codex evaluations.

Publication now tolerates bounded GitHub tag propagation delay while immediately rejecting mismatched revisions. Orchestration tests simulate delayed visibility, interrupted uploads with draft recovery, immutable published retries and verification timeout; these are mocked transport tests, not remote fault injection.
