# ChatGPT and Doubao evidence for the English learning handbook

Reviewed on 15 November 2026. These are current official-documentation findings and editorial applications, not provider execution, account verification, microphone tests or measured learning outcomes. Product interfaces vary; durable handbook instructions should name the feature and intended action rather than a fixed icon position or an unverified sequence.

## ChatGPT

### Voice conversation and dictation are different

Voice supports spoken back-and-forth within a chat. Dictation produces editable text before the user sends a message. To practise responding aloud, select Voice and allow microphone access; for a deliberate written response, dictate, inspect the transcript and send it. Users can ask for a slower pace or different response style during a voice exchange; this is not an exact playback-speed control. Current documentation says personality presets do not apply to Live. Available voice modes depend on plan, platform and account settings. Avoid hardcoding a model name or assuming every voice mode supports the same media. [ChatGPT Voice](https://help.openai.com/en/articles/20001274-chatgpt-voice), [Voice Dictation FAQ](https://help.openai.com/en/articles/12168547-voice-dictation-faq).

The Voice FAQ describes Advanced and Standard retiring on 11 December 2026. This is maintenance context, not a reason to make the learning chapter revolve around changing mode names. [Voice FAQ retirement notice](https://help.openai.com/en/articles/20001274-chatgpt-voice).

### Study mode supports guided learning

In a regular ChatGPT conversation, select Study from the available tools; the web composer can search for Study or use `@study`. It guides reasoning, explains in layers and can quiz one question at a time. Provide the exact language problem, what you already understand and a relevant excerpt. It can still give direct answers or make mistakes; request a hint and another attempt when useful. The current help excludes Temporary Chats, GPTs and Projects from the Study selector. Do not describe Study as automatically active in every chat or conflate voice dictation with a verified full Voice + Study workflow. [Using study mode](https://help.openai.com/en/articles/11780217-using-study-mode-in-chatgpt).

### Custom instructions and memory have different jobs

Custom instructions are standing response preferences. The current help documents Settings → Personalization on web/desktop and Customize ChatGPT on mobile. A learner can store simple English, concise responses and selective correction as preferences, then state the actual situation in the conversation. Standing preferences do not prove that an exercise happened. [Custom instructions](https://help.openai.com/en/articles/8096356-chatgpt-custom-instructions).

Memory can personalize from available sources but does not retain every detail of every conversation. Settings and availability differ. Keep an explicit short session summary when exact errors or previous answers matter; do not ask the reader to trust memory as a complete learning record or reliable error database. [Memory in ChatGPT](https://help.openai.com/en/articles/8590148-memory-in-chatgpt).

### File access must be checked against the task

The current upload FAQ supports document and image work subject to limits. It separately documents uploaded-audio transcription for eligible paid Chat accounts and workspaces, excludes Free at review time, and warns that attaching or previewing a recording can succeed while transcription is unavailable. Ask for a short excerpt or relevant page; if access fails, paste text or a usable transcript. Do not tell all users that any uploaded audio file is understood, or that a transcript establishes pronunciation. Exact limits and named models are volatile and need not appear in the public handbook. [Uploading files and audio](https://help.openai.com/en/articles/8555545-uploading-files-and-audio-to-chatgpt).

## Doubao

### Current official evidence and identity

Use `doubao.com` and ByteDance Seed for product evidence. The official service terms identify Beijing Chuntian Zhiyun Technology as the operator; the matching developer publishes the iOS and Mac store listings. Plausible search results calling themselves official on `doubaodk.com.cn`, `ai-doubao.com.cn` and `feimia.com.cn` were excluded. The official browser app returns no readable product-help text to this research tool; that is an extraction limitation, not proof that a feature is missing. [Service terms](https://www.doubao.com/legal/terms), [iOS developer listing](https://apps.apple.com/cn/app/id6459478672), [Mac developer listing](https://apps.apple.com/cn/app/id6683305962?mt=12).

### Text, voice input, real-time calls and search

The September 2026 privacy policy explicitly describes text, voice, image and file inputs; text and real-time spoken interaction; search requests; video/screen-sharing inputs; and memory controls. Those capabilities are not evidence that every client accepts the same files or that every source is fully readable. For a learner: choose ordinary text chat for explanations and draft comparison; choose real-time calling for turn-taking; provide a short accessible source; request search when current information matters and inspect the returned evidence. [Official privacy policy, sections 1.2 and 1.2.4–1.2.7](https://www.doubao.com/legal/privacy).

The mobile developer description distinguishes voice input from voice calls and lists search and photo input. It does not establish professional English-pronunciation grading, every supported file format or exact button locations. Do not infer those capabilities from marketing statements about accuracy. [Official iOS listing](https://apps.apple.com/cn/app/id6459478672).

ByteDance's 20 January 2025 launch article explicitly supports English conversation, interruptible real-time voice and responding to voice instructions. This supports trying an English conversation and asking for shorter/slower replies; the exact learning behaviour is an editorial suggestion. The release's language-specific scope is historical, and its comparative satisfaction claims should not become a current tool ranking. [ByteDance Seed launch article](https://seed.bytedance.com/zh/blog/%E8%B1%86%E5%8C%85%E5%AE%9E%E6%97%B6%E8%AF%AD%E9%9F%B3%E5%A4%A7%E6%A8%A1%E5%9E%8B%E4%B8%8A%E7%BA%BF%E5%8D%B3%E5%BC%80%E6%94%BE-%E6%83%85%E5%95%86%E6%99%BA%E5%95%86%E5%8F%8C%E9%AB%98).

### Memory is summarized context, not a transcript

Doubao's official FAQ says memory summarizes useful details and may omit conversation details. Some history-derived updates are periodic. Explicit remember/forget requests can update saved items, with capacity limits; settings allow review and management. Text extracted from voice exchanges can contribute, whereas uploaded images, files, links and video-call frames are excluded as memory sources. Advise keeping a short explicit learning summary for continuity instead of assuming a whole lesson or uploaded document is remembered. [Official Memory FAQ](https://www.doubao.com/legal/memory_faq).

### Desktop reading features are platform-specific

The Mac developer listing describes webpage reading, summaries, PDF/web-to-podcast, bilingual captions, screen-sharing voice and cross-device conversation history. These can inform an optional desktop suggestion: use a selected passage for explanation, then independently retell it. Do not imply that all these features exist in the mobile/web client, that generated podcasts exactly reproduce original audio, or that a transcript is an acoustic diagnosis. [Mac developer description and release notes](https://apps.apple.com/cn/app/id6683305962?mt=12).

## Suggested handbook applications

The following are authored learning techniques, not guaranteed product behaviour:

- Start with a short brief: the situation, the desired level of help and what the learner will do. Example: “I want to practise explaining a delayed project. Ask one question, wait for my answer, then correct one useful issue.”
- If responses become lectures, restate a smaller task: “Keep the explanation to two sentences, then let me try.” If correcting every detail blocks the conversation, defer feedback until a short section ends.
- For a difficult sentence, first state the interpretation, then ask which clause or word changes it. For writing, provide the intended audience and uncertainty before requesting a revision.
- When stuck, ask for one cue or opening phrase. After support, close the model answer and try a related example. These practices retain learner participation without a complicated prompt pack.
- At the end, select a small number of expressions and one next target. Save a concise summary outside the chat if continuity matters. In a new session, provide that summary and the actual material needed rather than assuming complete memory.
- Keep language feedback separate from factual correctness. For an important usage dispute, compare the intended meaning with a reliable example or source; repeated confident confirmation from the same model is not independent verification.

## Boundaries for publication

Avoid prices, fixed quotas, provider rankings, mandated paid subscriptions, claims of flawless memory, professional pronunciation scores and unsupported custom-agent creation paths. Keep exact dated evidence here; the public chapter can teach stable actions with brief conditions beside the feature they affect. No standalone custom role or uploaded file is required for either provider's basic learning workflow.
