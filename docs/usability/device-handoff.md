# Real-device handoff checklist

Status: **not executed**. This is a checklist and blank record, not a device certification or evidence of provider/audio compatibility.

Run on an actual iPhone in Safari and as an installed Home Screen app. Repeat on an Android device if that is a target device. Use fictional scenario background and an AI tool the participant already uses. Obtain consent before recording; avoid collecting personal chats or account credentials.

1. Open the app online, choose a language, and confirm it persists after reopening. Confirm the favorites label is the same for practice and reviews, and that saving a reusable combination is understandable.
2. Choose a coach, scenario and format; copy to the external AI. Check exact delivery, line breaks and whether the participant understands the next step. Record copying, actual AI use and actual audio use separately.
3. Return to the app, reopen a saved combination and confirm its safe selections. Confirm private background was not saved. Try the review handoff in the existing AI conversation.
4. After offline readiness is confirmed, reload offline and copy a prompt. Return online. If readiness is not confirmed, record that outcome rather than declaring offline support.
5. Where a staged update is available, accept it and verify exactly one reopening and retained preferences. Record the tested revision before and after. Do not reset a participant's local data to force an update.
6. Check keyboard appearance, sheet dismissal, browser Back, scrolling, and readable controls. If an external keyboard is available, dismiss the guide and remove a saved row; confirm visible focus moves logically.
